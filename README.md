# Fabiane Sarres | Da Nutrição à Tecnologia

Meu site de portfólio, feito como projeto final da disciplina de Programação Web com JavaScript (ADS · SENAC-DF).

🔗 **Acesse:** https://fabianesarres.github.io/minha-pagina/

## Sobre
Página sobre a minha transição de carreira da nutrição para a tecnologia, com uma calculadora de IMC que une as minhas duas áreas.

## Funcionalidades
- Tema claro e escuro, salvo no navegador (`if/else` + `localStorage`)
- Linha do tempo e habilidades montadas com array e laço `for`
- Calculadora de IMC com validação dos campos
- Histórico dos últimos cálculos salvo com `localStorage`
- Layout responsivo para computador e celular

## Tecnologias
HTML · CSS · JavaScript
